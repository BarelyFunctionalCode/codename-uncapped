# Codename Uncapped
This project is meant to be a community-driven spiritual successor to the game Legions: Fallen Empire (later re-released as Legions: Overdrive) in the Unity engine.
This means that we are taking the core game mechanics (movement, weapons, game modes), applying them to a completely new visual setting, and then adding much more new content that align with the original vibes of Legions. 

[Currently Under Development](https://github.com/users/BarelyFunctionalCode/projects/2/views/1)

## How to run

### WARNING
The latest version of this project is built for being on Steam. If you attempt to run this game outside of steam, you must at the very least have Steam running before starting the game executable. This way, the game will attempt to bootstrap the running Steam client when starting up.

### Just run the damn game
Go to the latest release found [here](https://github.com/BarelyFunctionalCode/codename-uncapped/releases) and download the zip file. Extract it and run the executable.

### Run in Unity
1. Install Unity Hub [here](https://unity.com/download).
2. Clone this repo, or download the zip and extract it.
3. Open Unity Hub, go to `Projects` and click `Open` and `Add project from disk`. Select the folder of the cloned repo.
4. Install the Unity version specified for the newly added Unity project.
5. Click on the project to open.
6. Click the triangle play button at the top of the screen.

## Contributing

If you would like you get involved, there are two main ways to contribute.

### Providing Feedback
You can take a look at our in-progress work by following the link at the top of the Readme or by navigating to the "Projects" tab at the top of the repo.
Feel free to comment on any existing issues or create new issues for something you think we missed, a bug that needs reporting, or a feature you'd like to see be added.
For any new Issues created, please add labels to it that help describe the purpose of the issue. 

### Helping with development
If you are more on the creatively-inclined side, feel free to fork the repository and contribute bug fixes, add missing art assets, or propose improvements/new features. Make sure to create a unique branch on your forked repo to put your work on, and then make a Pull Request to have your fork merged back into this repository.
