Singletons
    NetworkManager - Manage network peers
        - Accepts/Rejects connections
        - Authentication

		+ Dictionary<PeerID, PlayerID> Peers


    PlayerManager - Manage players
        - Listen to player inputs
		- Send/Receive chat between players
        - Select player loadout
            - Classes
                - Light
                - Medium
                - Heavy
                - Engineer
            - Weapons
                - Rocketlauncher
                - Grenade launcher
                - Chaingun
            - Accessories
                - Cores
                - Grenades

		+ List<PlayerID> Players


	EntityManager - Manages entities
        - Loading entities
            - Characters
            - Projectiles
            - Flags
            - Vehicles
        - Interactions between entities
            - Damage checks
            - Collision checks


    LevelManager - Manage level geometry
	    - Load/Unload level

		+ Scene CurrentLevel


    GameManager - Manages game mode
        - Assign players to teams
		- Load game mode
        - Track stats
            - Kill count
            - Deaths
            - Flag captures

		+ GameModeBase CurrentGameMode

	GameStats
	- Owns all events in the game mode
		- KILLS
		- FLAG_CAPTURES
		- DEATHS
	- Stats are accumulated to be queried for other purposes
		- displaying players' kill count
		- checking win conditions

		enum StatsGroup

		+ int ID
